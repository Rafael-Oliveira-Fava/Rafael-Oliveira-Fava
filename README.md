# Olá, eu sou o Rafael Oliveira Fava! 👋

Estudante de Desenvolvimento de Sistemas no **SENAI-SP**. Focado em transformar lógica de programação em soluções digitais funcionais, inovadoras e com foco total na experiência do usuário final.

### 🛠️ Tech Stack & Domínios

No ecossistema **Web**, domino o desenvolvimento com **React, TypeScript, JavaScript (ES6+), HTML5 e CSS3**, aplicando conceitos avançados de **UI/UX Design** e interfaces responsivas.

No **Backend e Infraestrutura**, trabalho com as linguagens **Python, PHP e C++**, gerenciando bancos de dados **MySQL e Supabase**, além de possuir experiência prática com **Arduino** em projetos de automação.

Minha experiência recente envolve a implementação de autenticação segura via **Google OAuth 2.0**, integração estratégica de **APIs REST** (como ViaCEP e Google Maps) e o desenvolvimento de assistentes baseados em **Inteligência Artificial**.
